# computercraft-wav
ComputerCraft-WAV is a bitmap viewer in ComputerCraft.

## Requirements
* A computer (any computer will do)
* A speaker
* A WAVE format file (either 16-bit or 8-bit uncompressed PCM audio, 
48 KHz sample rate recommended, otherwise the audio might be sped up or slowed down)

## How to use
(Copied from the output of the help command)

Usage: `wav <PATH TO WAVE FILE>/<--help>/<-h>`

\<PATH TO WAVE FILE\>: The path to a bitmap file, duh.
